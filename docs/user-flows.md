# Stray Rescue Grid — User Flows

## Citizen Reporting Flow

Report
→ Location
→ Animal Details
→ Photo
→ Ticket Creation
→ Confirmation

## Dispatcher Flow

Review Ticket
→ Set Priority
→ Assign Volunteer
→ Monitor Rescue
→ Select Facility
→ Close Ticket

## Volunteer Flow

Set Availability
→ Receive Assignment
→ Accept/Reject
→ En Route
→ Rescue
→ Submit Proof

## End-to-End Flow

Citizen Report
→ Ticket Created
→ Dispatcher Review
→ Priority Set
→ Volunteer Assigned
→ Rescue
→ Facility
→ Ticket Closed
