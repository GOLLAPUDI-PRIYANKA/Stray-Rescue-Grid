# Stray Rescue Grid — Presentation Flow

## 1. Problem

Stray animal rescue reports can be difficult to coordinate because reports,
locations, volunteers, rescue status, and facility capacity need to be
managed together.

## 2. Solution

Stray Rescue Grid provides a connected workflow:

Report → Prioritize → Assign → Rescue → Admit → Measure

## 3. Demonstration Story

### Citizen

A citizen reports an injured stray animal.

The system captures the location, animal information, description,
photograph, and creates a rescue ticket.

### Dispatcher

The dispatcher receives the new ticket, reviews the report, confirms the
priority, and selects an available volunteer.

### Volunteer

The volunteer receives the assignment, accepts it, travels to the location,
updates the rescue status, and records completion proof.

### Facility

The appropriate facility capacity is checked before the destination is
confirmed.

### Completion

The rescue ticket is closed after the outcome is recorded.

## 4. Key Features

- Citizen rescue reporting
- Location capture and correction
- Dispatcher command center
- Priority and status management
- Volunteer assignment
- Facility capacity management
- Completion proof
- Rescue metrics
