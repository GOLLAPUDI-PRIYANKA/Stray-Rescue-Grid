- [ ] Frontend uses the agreed API contract.

- [ ] Facility endpoints are connected.

## Complete Rescue Workflow

- [ ] Citizen can submit a report.
- [ ] Ticket reaches the dispatcher.
- [ ] Dispatcher can set priority.
- [ ] Dispatcher can assign a volunteer.
- [ ] Volunteer can accept the assignment.
- [ ] Volunteer can update rescue status.
- [ ] Completion proof can be recorded.
- [ ] Facility capacity can be checked.
- [ ] Ticket can be closed.
- [ ] Dashboard metrics reflect the completed rescue.
